# Gebäude 3D – Gesundheitszentrum (TECHNE e.U.)

Interaktives 3D-Modell eines Bestandsumbaus mit der Elektroplanung (Leuchten, Steckdosen, Daten, Sicherheitsbeleuchtung, Melder, Potentialausgleich). Eine einzelne HTML-Datei, läuft offline und im Browser – auch am Tablet.

**Ansehen:** https://ivan-nedeljko.github.io/techne-gebaeude-3d/

Bedienung: Ziehen = drehen · zwei Finger = zoomen/verschieben · Symbol antippen = Details · „Begehen“ = im Gebäude gehen (Tastenfeld unten links).

Planstand und Annahmen stehen im Reiter „Stand & Quellen“. Keine verbindliche Planunterlage – maßgeblich sind die freigegebenen Pläne.
